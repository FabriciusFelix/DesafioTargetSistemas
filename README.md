# Desafio Target Sistemas

Projeto feito em C# para resolver as questões do desafio técnico, abordando cálculo de comissão de vendas, movimentação de estoque de produtos e cálculo de juros por atraso.

Para rodar, você pode usar o comando `dotnet run` pelo terminal ou simplesmente abrir direto pelo arquivo `.exe` gerado na pasta do projeto, sem precisar configurar nada a mais.

O programa abre um menu no console onde dá para escolher qualquer uma das 3 opções, fazer os testes/lançamentos e voltar para o menu quando quiser.
